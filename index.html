// OUR MISSION

Beyond Textbooks. Into the Matrix.

SHIELD Cyber Society at National Institute of Technology Hamirpur was forged to bridge the gap between theoretical computing and real-world cybersecurity warfare. We provide hands-on environments where curious minds transform into capable security researchers, defenders, and ethical hackers.

// CORE FOUNDATIONS

The Four SHIELD Pillars

Every initiative, workshop, and operation within SHIELD is powered by four uncompromising principles.

PILLAR 01

LEARN

Decode the adversary’s playbook. Dive deep into computer architecture, networking internals, cryptosystems, and modern attack vectors through peer-to-peer bootcamps.

  • Hands-on Linux & Kernel Labs
  • Offensive TTP Dissections
  • Guided Security Certifications
PILLAR 02

BUILD

True understanding comes from construction. We build automated fuzzers, custom CTF challenges, defense telemetry scripts, and open-source security utilities.

  • Custom CTF Infrastructure
  • Security Tool Development
  • Exploitation & Defense PoCs
PILLAR 03

COLLABORATE

Cybersecurity is a team sport. We assemble competitive CTF units, host cross-department hackathons, and exchange research with industry professionals and alumni.

  • National & Global CTF Teams
  • Peer Code & Vulnerability Audits
  • Industry Guest Sessions
PILLAR 04

DEFEND

Defend what matters. We champion digital literacy, run campus-wide security awareness clinics, help secure student projects, and develop threat hunting capabilities.

  • Campus Cyber Hygiene Drives
  • Blue Team Live Simulations
  • Responsible Disclosure Culture
// SPECIALIZATION TRACKS

The 8 Core Domains of SHIELD

Explore our specialized operational tracks. Whether your passion lies in dissecting malware or hunting web zero-days, SHIELD has a dedicated division for you.

TRACK 01

Network Security

Packet analysis, perimeter fortification, zero-trust protocols, firewall administration, Wireshark packet capture analysis, and enterprise segmentation defense.

Wireshark Snort/Suricata TCP/IP Protocol Firewalls
TRACK 02

Web Application Security

Dissecting modern web apps, OWASP Top 10 vulnerabilities (SQLi, XSS, CSRF, SSRF, IDOR), GraphQL & REST API fuzzing, and ethical bug bounty hunting.

Burp Suite Pro OWASP Top 10 SQLMap API Security
TRACK 03

Cryptography

Theoretical and applied cryptosystems. Symmetric and asymmetric encryption (AES, RSA, ECC), hash cracking, side-channel attacks, and post-quantum cryptography.

RSA / ECC SageMath Hashcat Cryptanalysis
TRACK 04

Digital Forensics

Cyber incident investigation, disk image carving, volatile memory dumps analysis, Windows artifact analysis, file system reconstruction, and timeline auditing.

Volatility 3 Autopsy FTK Imager Memory Carving
TRACK 05

Malware Analysis

Static and dynamic disassembly of malicious binaries, sandbox detonation, decompilation with Ghidra and IDA Pro, x86/x64 assembly tracing, and YARA rule formulation.

Ghidra x64dbg / GDB YARA Cuckoo Sandbox
TRACK 06

Cloud Analysis

Cloud infrastructure audit, AWS/Azure/GCP IAM misconfiguration hunting, Kubernetes container escape techniques, serverless security, and Cloud Trail log forensics.

AWS / GCP Audit ScoutSuite Docker / K8s Pacu
TRACK 07

Security Operations (SOC)

Blue team defenses, SIEM log correlation, real-time threat hunting, intrusion detection systems, incident response playbooks, and MITRE ATT&CK mapping.

Wazuh SIEM Splunk Zeek MITRE ATT&CK
TRACK 08

Offensive Security

Red Teaming methodology, Active Directory penetration testing, custom payload crafting, privilege escalation on Linux/Windows, and physical cyber defense audits.

Metasploit Active Directory Mimikatz BloodHound
